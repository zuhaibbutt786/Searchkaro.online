Create Clickable Hyperlinks in PowerShell Console Output

Learn how to emit a clickable URL from PowerShell using ANSI escape sequences and make it visible in TFS 2015 build logs.

Console output is plain text by default

The Windows PowerShell host renders strings exactly as they are sent. Without special handling the console cannot turn a URL into an interactive element, so it appears as ordinary text.

Modern terminals understand ANSI hyperlink codes

Starting with Windows 10 build 1809 and PowerShell 7, the console and Windows Terminal support the ECMA‑48 "OSC 8" escape sequence. When a host recognises this sequence it displays the enclosed text as a clickable hyperlink that opens the supplied URL in the default browser.

Emit a hyperlink with escape codes

The sequence consists of three parts: the opening ESC ]8;;<url> ESC \, the visible text, and the closing ESC ]8;; ESC \. Use the PowerShell back‑tick escape "`e" for the ESC character.

When the host supports it, the text becomes a live link.

$url = 'http://something.com'
$esc = "`e"
# Open sequence, visible text, close sequence
Write-Host "${esc}]8;;$url${esc}\`a$url${esc}]8;;${esc}\`a"

Make the link work in TFS 2015 build logs

TFS 2015 treats any plain URL in a build log as a clickable link. If the build agent runs PowerShell 7, the ANSI hyperlink will also be rendered in the log viewer that supports it. For agents that use Windows PowerShell 5.1, fall back to outputting the raw URL; TFS will still turn it into a link.

Fallback for hosts without ANSI support

If the console does not recognise OSC 8, the escape characters are displayed as garbled text. Guard the output with a version check:

```powershell if ($PSVersionTable.PSVersion.Major -ge 7) { # emit ANSI hyperlink (see previous section) } else { Write-Host $url # plain URL – TFS will still link it } ```

Takeaway: Use the ANSI OSC 8 sequence (`ESC]8;;URLESC\`) to write clickable links when the host (PowerShell 7+, Windows Terminal) supports it.

People also ask

Will the hyperlink work in the classic PowerShell ISE?

No. The ISE does not interpret ANSI escape sequences, so only the plain URL will be shown.

Do I need any modules to enable this feature?

No external module is required; the functionality is built into the console host that supports ANSI.

Can I change the displayed text without affecting the target URL?

Yes. Place any string between the opening and closing sequences; the URL stays in the opening part.
