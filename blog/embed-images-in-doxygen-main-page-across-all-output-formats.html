Embed Images in Doxygen Main Page Across All Output Formats

Use Doxygen’s \image directive and IMAGE_PATH to reference images in Markdown, ensuring compatibility with HTML, PDF, man pages, and Eclipse help.

Problem Overview

When generating documentation with Doxygen, developers often embed images in the main page using Markdown syntax like ![Logo](../resources/logo.png). That approach works for HTML but fails for other formats because the relative path depends on the output directory structure.

Doxygen Image Handling

Doxygen can copy image files from the source tree into every output format. The \image command accepts an optional format argument; omitting it causes the image to appear in all supported outputs. The command also accepts a caption that will be rendered appropriately in PDF, man pages, etc.

Configuring IMAGE_PATH

Add the directory that holds your images to the IMAGE_PATH setting in the Doxyfile. For example:

``` IMAGE_PATH = resources ```

This tells Doxygen to search for image files in the resources folder and to copy them into the output directories.

Markdown Syntax with \image

Replace the Markdown image syntax with the Doxygen command inside your mainpage.md:

``` \image logo.png "The Logo" ```

Because IMAGE_PATH is set, Doxygen resolves logo.png relative to resources and copies it to every output format. No relative path tricks are needed.

Example Project Layout

A minimal layout that works for all formats:

``` work/ ├─ mainpage.md ├─ resources/ │ └─ logo.png └─ Doxyfile ```

Running doxygen will produce html/index.html, latex/refman.pdf, man/man1/, etc., all containing the logo.

Common Pitfalls

- Using Markdown syntax (![…]) only works for HTML. - Forgetting to set IMAGE_PATH causes images to be ignored. - Specifying a format (e.g., \image html logo.png) limits the image to that format only.

Takeaway: Use \image without a format specifier and set IMAGE_PATH to embed images consistently across all Doxygen output formats.

People also ask

Can I use Markdown image syntax for all formats?

No, Markdown images render only in HTML; use \image for cross‑format support.

Does Doxygen copy images automatically?

Yes, any file referenced by \image and located in an input directory or IMAGE_PATH is copied to each output.
