Shuffle an Array of Objects in JavaScript – Fisher‑Yates

Learn how to randomize an array of objects in JavaScript using the Fisher‑Yates algorithm, preserving object references.

Why Objects Need Shuffling

An array of objects behaves like a plain array; each element is a reference to an object. The Fisher‑Yates algorithm swaps indices, so it works identically for primitives and objects.

Implementing Fisher‑Yates for Objects

Create a copy of the array if immutability is required, then iterate from the end to the beginning, swapping elements with a randomly chosen earlier index.

function shuffleObjects(arr) {
  const result = arr.slice(); // shallow copy
  for (let i = result.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [result[i], result[j]] = [result[j], result[i]];
  }
  return result;
}

const people = [
  { id: 1, name: 'Alice' },
  { id: 2, name: 'Bob' },
  { id: 3, name: 'Carol' }
];
console.log(shuffleObjects(people));

Common Mistakes to Avoid

1. Using `Math.random() * arr.length` inside the loop can bias the shuffle. 2. Mutating the original array when a copy is expected. 3. Forgetting to handle empty arrays, which would skip the loop safely.

Testing the Shuffle

Run the shuffle multiple times and compare the output order. A simple test verifies that all original objects appear exactly once in each shuffled result.

function testShuffle() {
  const original = [1, 2, 3, 4, 5];
  const seen = new Set();
  for (let i = 0; i < 100; i++) {
    const shuffled = shuffleObjects(original);
    seen.add(shuffled.join(','));
  }
  console.log('Unique permutations:', seen.size);
}

testShuffle();

Takeaway: Use Fisher‑Yates to reliably shuffle object arrays without mutating originals.

People also ask

Can I shuffle in place without copying?

Yes, call the algorithm directly on the array, but the original order will be lost.

Does the algorithm preserve object references?

Yes, it only swaps indices; the objects themselves remain unchanged.
