Get Latest Universe Value with DAX Measure in Power Pivot

Use a single DAX measure to fetch the most recent Universe amount based on the Date column.

Problem Overview

The goal is to return the Universe value that corresponds to the most recent date in the current filter context. The user’s attempt returns the grand total because the filter context is not properly limited to the row with the maximum date.

Why the Grand Total Appears

Using CALCULATE with FILTER(tbData, tbData[Date] = [Last Universe Date]) still evaluates the measure over the entire table. When the measure inside the FILTER references a column that is not aggregated, Power BI expands the context to the entire table, causing the SUM of Universe to be calculated for all rows.

Correct DAX Pattern

1. Find the maximum date that satisfies the current context. 2. Return the Universe value that belongs to that date. 3. Use CALCULATE with a single filter expression that directly compares the Date column to the maximum date. 4. Avoid using EARLIER or multiple CALCULATE layers that can break the context.

VAR MaxDate = CALCULATE(MAX(tbData[Date]), ALLSELECTED(tbData))
RETURN CALCULATE(SUM(tbData[Universe]), tbData[Date] = MaxDate)

Full Measure Example

The measure below can be placed in any visual or used in other calculations. It respects slicers, page filters, and row context when used in a table.

LastUniverseValue =
VAR MaxDate = CALCULATE(MAX(tbData[Date]), ALLSELECTED(tbData))
RETURN CALCULATE(SUM(tbData[Universe]), tbData[Date] = MaxDate)

Usage Tips

• Place the measure in a card to display the latest value. • Combine it with other measures (e.g., % of total) by referencing the same variable. • If multiple rows share the same latest date, the measure returns the sum of all corresponding Universe values.

Takeaway: A single measure that filters on the maximum date returns the latest Universe value without producing the grand total.

People also ask

How do I handle ties when multiple rows share the latest date?

The measure will sum all Universe values for that date. If you need a single row, add another distinguishing column to the filter.

Can I use this measure in a line chart?

Yes, but the chart will show a constant value because the measure ignores the X‑axis. Use a separate date column for the axis.
