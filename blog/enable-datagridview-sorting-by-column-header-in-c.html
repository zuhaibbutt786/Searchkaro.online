Enable DataGridView Sorting by Column Header in C#

Learn how to sort a DataGridView bound to a List by clicking column headers in C#.

Why Sorting Fails with List Binding

A plain List<T> implements IList but not IBindingList, so the DataGridView cannot invoke a sort operation automatically. When the grid is bound directly to a List, clicking a header triggers no change in the underlying data source, resulting in a static view.

Wrap the List in a BindingList

BindingList<T> implements IBindingList and exposes a Sort method. Converting the List to a BindingList gives the grid a sortable collection. The conversion is one‑liner:

var bindingList = new BindingList<Data1>(myList);

Use a BindingSource to Enable Sorting

BindingSource acts as an intermediary that understands sorting commands. Assign the BindingList to the BindingSource, then bind the DataGridView to the BindingSource. This setup allows the grid to call Sort on the underlying list.

var bs = new BindingSource();
bs.DataSource = bindingList;
dgv.DataSource = bs;

Handle ColumnHeaderMouseClick to Apply Sort

The DataGridView raises ColumnHeaderMouseClick when a header is clicked. In the handler, determine the clicked column and call BindingSource.Sort with a column name and direction. The grid then refreshes automatically.

private void dgv_ColumnHeaderMouseClick(object sender, DataGridViewCellMouseEventArgs e)
{
    var col = dgv.Columns[e.ColumnIndex];
    var direction = "ASC"; // toggle logic omitted for brevity
    bs.Sort = col.DataPropertyName + " " + direction;
}

Common Pitfalls and Tips

• Ensure DataPropertyName matches the property name in the data class. • Avoid setting AutoGenerateColumns to false unless you manually create columns. • If you need case‑insensitive sorting, implement IComparer and pass it to BindingList.Sort.

Takeaway: By wrapping a List in BindingList and using a BindingSource, DataGridView sorting via column headers becomes straightforward in C#.

People also ask

Can I sort a DataGridView bound to a List without using BindingSource?

Only if you convert the List to a BindingList and set it as the DataSource; the grid will then use the BindingList’s Sort method.

What if my data class has no parameterless constructor?

BindingList and BindingSource require a public parameterless constructor to create instances for new rows; otherwise set DataGridView.ReadOnly to true.

How do I toggle ascending/descending on successive clicks?

Store the last sorted column and direction in a field, then invert the direction when the same column header is clicked again.
