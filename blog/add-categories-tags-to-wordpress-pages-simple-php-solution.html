Add Categories & Tags to WordPress Pages – Simple PHP Solution

Learn how to attach standard categories and tags to pages using core WordPress functions without converting to posts.

WordPress Taxonomy Basics

WordPress stores content in post types such as "post" and "page". Taxonomies (categories, tags, custom terms) are linked to post types. By default, pages do not have the built‑in categories or tags taxonomy attached.

Enable Built‑In Taxonomies for Pages

You can simply tell WordPress to use the existing categories and tags taxonomy for the page type. Add the following to your theme’s functions.php or a site‑wide plugin.

add_action( 'init', function() {
    register_taxonomy_for_object_type( 'category', 'page' );
    register_taxonomy_for_object_type( 'post_tag', 'page' );
});

Create a Custom Taxonomy for Pages

If you prefer a dedicated taxonomy, register one that only applies to pages. The code below creates a "Page Tags" taxonomy that behaves like tags but is isolated to pages.

add_action( 'init', function() {
    register_taxonomy( 'page_tag', 'page', array(
        'label' => 'Page Tags',
        'hierarchical' => false,
        'rewrite' => array( 'slug' => 'page-tag' ),
        'show_ui' => true,
        'show_admin_column' => true,
    ));
});

Using the Taxonomy in the Page Editor

Once the taxonomy is registered, the tag box appears in the page editor under "Tags" (or the custom name you set). You can add, edit, or remove terms just like with posts. The terms are stored in the same tables, so queries and archives work normally.

SEO & Performance Tips

Because pages are typically static, adding many terms can increase query load. Use the built‑in WP_Query with tax_query to limit results, and consider caching page archives with a plugin or transients. For SEO, ensure that the taxonomy archive URLs are included in your sitemap and that the taxonomy is indexed by search engines.

Takeaway: Pages can have categories and tags by registering taxonomies for the page post type, eliminating the need to convert to posts.

People also ask

Do I need a plugin to add tags to pages?

No. Core WordPress functions suffice – just register the taxonomy in functions.php.

Will this affect the page permalink structure?

Only if you change the rewrite slug. The default page permalink remains unchanged.
