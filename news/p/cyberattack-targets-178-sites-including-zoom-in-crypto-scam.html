Cyberattack Targets 178 Sites, Including Zoom, in Crypto Scam

A massive cyberattack has compromised 178 major websites, including Zoom and CNN, in a bid to steal cryptocurrency and infect iPhones. Security experts advise users to take immediate steps to safeguard their accounts.

Latest developments

A coordinated attack struck 178 prominent websites, with Zoom and CNN among the victims, as attackers sought to siphon cryptocurrency and infect iPhone users. The malware was distributed through a sophisticated A/B testing framework, exploiting the popular web optimization tool Optimizely to deliver malicious code to unsuspecting visitors. Security teams identified the same code across multiple sites, indicating a single, well‑planned operation.

The malicious payload was designed to harvest crypto wallet credentials and to embed a backdoor that could compromise iPhone operating systems. Early analysis shows that the code attempted to bypass standard security checks, allowing it to run silently on devices that had not yet applied the latest iOS updates.

In response, federal cybersecurity agencies released alerts urging site operators to disable third‑party optimization scripts and to conduct thorough code reviews. Several affected companies announced emergency patches, while law‑enforcement agencies began tracing the origin of the attack to a network of compromised servers in Eastern Europe.

Why it matters

Pakistani users rely heavily on Zoom for remote learning, telemedicine, and business meetings. The breach exposes them to potential credential theft, which could lead to unauthorized access to personal and corporate accounts. Additionally, the malware’s focus on iPhones raises concerns for a large segment of the population that uses Apple devices for daily transactions.

Beyond direct theft, the attack highlights the vulnerability of widely used optimization platforms. If a single tool can serve as a vector for malware, users across the country must reassess the security of third‑party services integrated into their workflows. Protecting personal data and financial information becomes a shared responsibility between users and service providers.

Background

Large‑scale cyberattacks on high‑profile websites are not new; however, the use of A/B testing platforms as delivery mechanisms marks a notable shift. Optimizely, a tool that allows developers to test different code versions, has been co‑opted by attackers to serve malicious scripts to a broad audience.

Previous incidents have shown that attackers can embed malware within seemingly innocuous code segments, making detection difficult for conventional security solutions. The 178‑site breach demonstrates the scale that can be achieved when a single vulnerability is leveraged across multiple platforms.

Cybersecurity experts warn that the integration of optimization tools into core website functionality creates a new attack surface that must be monitored closely.

What happens next

Affected companies are expected to release security patches within the next 48 hours, and cybersecurity firms will likely conduct forensic analyses to determine the full scope of the breach. Users are advised to update their software, change passwords, and monitor accounts for suspicious activity.

Regulatory bodies may issue guidance on the use of third‑party optimization services, and legal investigations could target the operators of the compromised servers. The incident is likely to prompt a review of industry best practices for web security and user data protection.

Summary
